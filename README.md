## About the Project

This repository contains 10 Python case studies developed as part of the *Python Activity-Based Learning* assignment.

The main purpose of this project is to understand and apply basic Python programming concepts to solve simple real-world problems.

Each case study includes a problem description, objective, algorithm, pseudocode, flowchart, Python source code, sample test cases, and output.

The programs are designed using beginner-friendly Python concepts and are suitable for learning and practical implementation.

## Objectives

- Understand basic Python programming concepts.
- Develop logical and problem-solving skills.
- Learn how to write algorithms and pseudocode.
- Represent program logic using flowcharts.
- Implement solutions using Python.
- Test programs with different inputs and observe their outputs.

## List of 10 Case Studies

### 1. Case 12 – Attendance Recovery Computation
*Description:* Calculates the number of additional classes a student must attend to reach the required 75% attendance.

*Concepts Used:*
- Variables
- Arithmetic operators
- While loop
- If-else conditions

### 2. Case 13 – ATM Transaction Sequence Simulation
*Description:* Simulates basic ATM operations such as depositing money, withdrawing money, and checking the final account balance.

*Concepts Used:*
- While loop
- If-elif-else
- User input
- Arithmetic operators

### 3. Case 27 – Symmetric Number Pattern Generator
*Description:* Generates a symmetric number pattern based on the number of rows entered by the user.

*Concepts Used:*
- Nested for loops
- Range function
- Print statements

### 4. Case 29 – Password Policy Validation
*Description:* Checks whether a password satisfies two basic conditions: minimum length of 8 characters and at least one digit.

*Concepts Used:*
- Strings
- For loop
- If-else conditions
- String methods

### 5. Case 31 – String-Based Examination Answer Evaluation
*Description:* Compares student answers with a predefined answer key and calculates correct, incorrect, and unanswered questions.

*Concepts Used:*
- Lists
- Strings
- For loops
- Conditional statements

### 6. Case 42 – Student Marks Matrix Analysis
*Description:* Collects marks of three students in three subjects, calculates their totals and averages, and identifies the student with the highest total.

*Concepts Used:*
- Nested lists
- Nested for loops
- Sum function
- If conditions

### 7. Case 45 – Weekly Electricity Consumption Matrix
*Description:* Records the daily electricity consumption of different appliances for seven days and identifies the appliance with the highest weekly consumption.

*Concepts Used:*
- Lists
- Nested loops
- Sum function
- Conditional statements

### 8. Case 49 – Tuple-Based Product Catalogue Audit
*Description:* Maintains a product catalogue using tuples, calculates the total stock value, and identifies products with low stock.

*Concepts Used:*
- Tuples
- Lists
- For loops
- Arithmetic operators
- If-else conditions

### 9. Case 51 – Bus Passenger Occupancy Simulation
*Description:* Simulates passenger boarding and alighting at three bus stops and checks whether the bus capacity is exceeded.

*Concepts Used:*
- Variables
- For loop
- If-else conditions
- Arithmetic operators

### 10. Case 53 – Food Waste Monitoring System
*Description:* Records meals prepared and served over three days, calculates leftover food and wastage percentage, and identifies high food waste.

*Concepts Used:*
- Lists
- For loops
- Arithmetic operators
- Conditional statements

## How to Run the Programs

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Make sure Python is installed on your computer.
4. Open the required .py file.
5. Click the *Run Python File* button.
6. Enter the required input in the terminal.
7. Observe and verify the output.

Example:

bash
python Case_12.py
